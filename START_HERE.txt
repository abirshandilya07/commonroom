COMMONROOM — START HERE

1. Extract the whole ZIP into a NEW folder.
2. Install Node.js 24.x. Reopen your terminal if Node was just installed.
3. Windows: double-click START_WINDOWS.cmd inside the extracted folder.
   Or open a terminal here and run:

   npm ci
   npm run dev

4. Visit http://localhost:5173 after Vite says it is ready.
5. Use a normal window and an incognito window to try two accounts.
6. Encryption starts automatically. Privacy & backup (below your sidebar name)
   offers an optional recovery backup for another browser or cleared site data.
7. Use the compose icon beside Commonroom for direct messages or Group chat.
   Groups need 3–256 people, each having opened their chats once.
8. Open the notification bell to enable optional sound and desktop alerts.

UPGRADING? Stop the old app and back up your project first. This update changes
both frontend/backend and migrates the database. Read README.md before copying
your existing backend/data folder. Earlier messages stay unencrypted.
Encryption is a hackathon prototype without forward secrecy; see docs/ENCRYPTION.md.

YOU ARE IN THE RIGHT FOLDER IF YOU SEE ALL OF THESE TOGETHER:
package.json
package-lock.json
frontend
backend
START_WINDOWS.cmd

The updated ZIP puts these files at its root, with no extra commonroom folder.

For the OLDER ZIP, your terminal may be one folder too high. From the folder
shown in your screenshot (~/Commonroom_starter), run:

cd commonroom
ls package.json package-lock.json
npm ci
npm run dev

Do not create an empty lockfile. If the files are missing, re-extract the ZIP.
No database service, Docker, or API key is needed.
Read README.md for configuration and existing-project update instructions.
